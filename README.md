# LOFT | Laboratorio de Óptica y Fotónica
Sitio web del **Laboratorio de Óptica y Fotónica (LOFT)**, Departamento de Física, Facultad de Ciencias Exactas y Naturales, Universidad de Buenos Aires.
- **Sitio oficial:** loft.df.uba.ar
- **Páginas principales:** `index.html` (español) e `index_en.html` (inglés).

## Para editar:
- Guardar `index.html` e `index_en.html` en codificación **UTF-8**.
- Mantener nombres de carpetas y archivos en minúsculas.
- Evitar imágenes y documentos pesados; si no, comprimir.
- El repositorio es público: no incluir contraseñas, datos de acceso ni información privada.
